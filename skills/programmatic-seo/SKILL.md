# Programmatic SEO

## Scope
Programmatic SEO covers scalable page strategy, template design, content/data requirements, keyword research, internal linking, and indexation planning. It does not replace a technical SEO audit.

## Core rule
Every generated page must provide genuine, useful, differentiated value. Never publish thin pages that merely swap a keyword, industry, competitor, tool, or term into the same template.

## Playbooks

### Personas / Industry pages
Use for patterns such as CRM for [industry]. Research search demand and intent for each industry variation. Define industry-specific data, workflows, pain points, examples, terminology, proof, and product value. Use clean URLs such as /industries/real-estate. Use a reusable template while requiring meaningful unique content/data per page. Build an industry hub and contextual internal links.

### Comparisons
Use for patterns such as [A] vs [B]. Research each comparison keyword and intent. Cover positioning, capabilities, workflows, trade-offs, migration considerations, and verifiable pricing. Supply comparison-specific evidence. Prefer /compare/notion-vs-asana. Cross-reference the competitors playbook when available. Quality-check factual accuracy, freshness, differentiation, and balanced representation.

### Integrations
Use for patterns such as [tool] integration. Research [tool] + [product] demand and intent. Include what the integration does, setup steps, supported workflows, use cases, limitations, troubleshooting, and concrete examples. Require integration-specific evidence where available. Prefer /integrations/slack. Create an integrations hub. Use structured data only when accurate and valid.

### Glossary
Use for [term] definition. Include definition, examples, related concepts, practical application, and product relevance where appropriate. Prefer /glossary/[term]. Create alphabetical and categorical hub navigation. Use DefinedTerm structured data where appropriate. Prioritize high-value terms and contextual internal links. Do more than reproduce dictionary definitions.

## Indexation and quality controls
Verify unique substantial content/data, search-intent alignment, contextual internal links, XML sitemap coverage, robots.txt/meta robots, canonicals, duplicate/near-duplicate risk, crawl efficiency, and intentional handling of low-value pages. If many pages are not indexed, investigate these signals plus Search Console data; do not assume crawl budget is the cause merely because there are hundreds of pages.

## Technical SEO boundary
For technical audits involving crawl errors, 404s, server responses, robots directives, canonicals, or implementation defects, use or cross-reference the seo-audit skill rather than treating this skill as the full audit.

## Output
Provide the page model, unique data requirements, keyword/intent approach, URL pattern, internal-link architecture, indexation strategy, and quality gates.
